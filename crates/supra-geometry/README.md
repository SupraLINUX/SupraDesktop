# SupraGeometry — M01
Primer contrato experimental independiente de toolkit: rectángulo local, radio acotado, modelos circular y superelíptico local, membership y cobertura CPU de referencia 4x4. No SDF exacta, no contorno Bézier ni calibración macOS. Pruebas de simetría, límites, geometría y cobertura. Usar solamente como candidato de laboratorio.
