# Packaging Arch del escritorio

Reservado a empaquetado portable de SupraDesktop para Arch, sin requerir SupraLINUX ni su backend de despliegue. Recetas de imagen, snapshot y capas de la distribución se gestionan en [SupraLINUX](https://github.com/SupraLINUX/SupraLINUX/blob/main/packaging/arch/README.md). Sin paquetes implementados.
