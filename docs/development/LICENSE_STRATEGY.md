Apache-2.0 has explicit patent provisions and can be incorporated into GPLv3 combined works (not GPLv2-only); MIT, ISC, BSD and Zlib permissive options generally permit incorporation subject to notices. Unicode-3.0 must be retained in addition to the chosen MIT/Apache branch for unicode-ident; dpi AND requires both. GPL does not prohibit commercial distribution or independently developed proprietary apps running on a desktop; close linking/plugin boundaries need separate analysis. SDK MIT OR Apache-2.0 only for independently authored code and if API portability merits permissive distribution. AGPL adds network-source obligations to modified remotely used covered software; not needed for a local-first desktop absent a different objective. MPL-2.0 is file-level copyleft, not the same derivative protection as GPL. Keep third-party license texts and notices, corresponding source and relevant build/install scripts for covered binaries; image aggregation does not relicense all packages. Avoid proprietary Apple artwork, branding and copied implementation; independent recreation does not automatically clear trademark/design risks. A final pre-release review is required.
