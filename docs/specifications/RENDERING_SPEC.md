# SupraRenderer / SupraGlass

Pipeline candidato: escena y visibilidad → backdrop situado detrás del material → espacio cromático definido → pirámide blur → SDF/curvatura/normales → refracción y muestreo → vibrancy/tinte → Fresnel/reflejos/dispersión → máscaras/bordes/sombras → composición premultiplied alpha → presentación. Orden sujeto a calibración; referencia gaussiana separada de Dual Kawase optimizado. Separar blur behind-window (compositor) y within-window (toolkit); no inferir regiones internas de apps externas.

Cache por salida y región de daño; invalidar al cambiar contenido inferior, escala, color, geometría, material o foco. Evitar muestreo de superficies superiores/protegidas. Texture pooling, clipping correcto, occlusion y direct scanout cuando no se requiera composición. Escalado fraccional, múltiples pantallas, perfiles SDR/HDR, explicit sync. Fallback sin shader y opaco para accesibilidad/fallo. GLES/EGL inicial; Vulkan solo tras benchmark y ADR.

SupraLab debe renderizar recetas y controles aislados, exportar capturas/metadata y comparar con patrones deterministas. Validar bordes, costuras, alfa, gamut, sombras, refracción y movimiento. No llamar Liquid Glass a una mera transparencia.

## CPU content retention experiment
Original cpu_content module in supra-window is a bounded copy reference for ARGB8888/XRGB8888. It validates stride/offset/span and integer scale/transform, copies only pixel rows (not padding) into owned immutable allocations, and retains copies across asynchronous renderer snapshots. Budget counts live pixel payload even after replacement/detach until all Arc holders drop; allocator overhead is not included. A trusted transport must provide a safely readable slice bound to the actual buffer; no fd mapping/SIGBUS containment, format conversion, damage, viewport, physical rendering or GPU import. No claim that CPU copy is the eventual fast path. See [Wayland core](https://wayland.freedesktop.org/docs/html/apa.html). CI pending.

## Retained-surface composition reference
New internal supra-render-cpu crate depends on supra-window and supra-scene only; neither depends on rendering. It consumes immutable retained snapshots and composes actual little-endian ARGB/XRGB pixels using integer premultiplied source-over, clipping, integer scale and inverse buffer transform sampling. Output scale 1, nearest sample, nonnegative placements, opaque black background; no viewport, color management, GPU, glass, presentation or performance claim. Scene planner drives changed-region composition; stale/reused revision with different retained storage or state forces conservative redraw. Tests cover known asymmetric transforms, alpha/clipping, zero unchanged writes, moved/removed surfaces, duplicate rejection and equality against fresh render. Full output scan for damage membership is intentionally a reference, not a production optimization. See [Wayland core](https://wayland.freedesktop.org/docs/html/apa.html). CI pending.

## Incremental optical prefix experiment
[46073199805](https://github.com/SupraLINUX/SupraDesktop/actions/runs/46073199805) PASS for full optical reference and disjoint damage traversal. New optical::incremental caches immutable completed prefixes, derives conservative sampling radius from Gaussian truncation + depth*slope (Snell refraction toward normal cannot bend more than atan(slope)) + one bilinear texel, plans each prefix independently and rewrites only disjoint damage regions. Unchanged prefixes share Arc buffers; modified prefixes clone old frame privately before publication. Full-plane RGB Gaussian remains when a touched glass region requires it; no incremental blur or memory-bandwidth/timing claim. Limit 16 layers and 262144 output pixels. Changed material or ambiguous same revision triggers conservative full redraw of affected and upper prefixes. 24-frame movement/reorder fixture compares each pixel with independent full-compose reference, tests no-work unchanged, upper-only, invalid transaction, material change and empty scene. Metrics count prefix evaluations/optical pixels and full-plane blur passes, not time. CI pending.
